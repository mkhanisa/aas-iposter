# iPoster iFrames for AAS 247

## Viewers Included

- **Dual Panel Viewer** (`TIC313408643_dual_panel_viewer.html`)
  - 2D and 3D interactive visualization of the targets across all frames
  - Frame slider, star hover info, pan/zoom

- **Split Aperture Viewer** (`TIC313408643_split_aperture_viewer.html`)
  - Visualizes split-aperture photometry geometry for each frame
  - Frame slider, interactive pan

- **Mini-AIJ Full Frame Viewer** (`frame_1_mini_aij.html`)
  - Full FITS image display with star overlays, pan/zoom, and downsampling for web
